# COPA Quantum Challenge

## Overview

This repository contains the source code and executable for our submission to the **COPA Quantum Challenge** hosted by MPhasis. The app is designed to interact with quantum-based solutions and is packaged into an executable for easy usage.

## Requirements

Before you run the app, make sure you have the following:

- **Windows** operating system (the app is packaged as a `.exe` file)

## How to Use the Code and Launch the App

1. **Clone the Repository**  
   First, clone the repository to your local machine using GitHub Desktop or the following command in your terminal:  
   `git clone https://github.com/zachmanson/COPA-Quantum-Challenge.git`

2. **Navigate to the `dist` Folder**  
   Once the repository is cloned, open your file explorer (Windows) or Finder (Mac) and go to the directory where you cloned the repository. Navigate into the `dist` folder located inside the `Mphasis-quantum` directory. The full path should look like this:  
   `Mphasis-quantum/dist`

3. **Launch the Application**  
   Inside the `dist` folder, locate the `gui.exe` file. Double-click on the `.exe` file to launch the application.
